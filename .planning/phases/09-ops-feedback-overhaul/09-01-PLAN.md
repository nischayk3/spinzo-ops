## Wave 1 — Backend, Timers/Rules, & Standalone Utilities/Modals (3 Parallel Disjoint Tracks)

### Track W1-Backend (`ops/functions/`)
- **Files:** `ops/functions/dispatch.js`, `ops/functions/index.js`, `ops/functions/dispatch.test.js`
- **Specs:**
  1. **`R15` (Unassign Pickup & Delivery Hold + Field Cleanup)**:
     - `unassignPickup`: delete `riderId`, `riderName`, `pickupRider` from user & vendor order docs; write `ops_queue/{orderId}` with `status: 'manual_hold'`, `manualHold: true`. Guard `drainScheduledRiderTasks` and `onShiftCatchUp` to skip `manualHold === true || status === 'manual_hold'`.
     - `unassignDelivery`: delete `deliveryRiderId`, `deliveryRiderName`, `deliveryRiderPhone`, `deliveryRider`, `riderId`, `riderName` from user & vendor order docs; set `manualDeliveryHold: true` on order doc (and `status: 'manual_hold'`, `manualHold: true` on `ops_delivery_tasks/{orderId}`). Guard `syncDeliveryTask`, `drainScheduledRiderTasks`, and `onShiftCatchUp` to skip tasks/orders with `manualHold === true || manualDeliveryHold === true || status === 'manual_hold'`.
     - Clear `manualHold` / `manualDeliveryHold` on manual `assignTaskToRider` and slot reschedule.
  2. **`R16` (Delivery Auto-Assign Status Parity)**:
     - In `syncDeliveryTask`, `drainScheduledRiderTasks`, `onShiftCatchUp`, and `markOutForDelivery`, whenever a delivery rider is assigned, immediately set `order.status = 'out_for_delivery'`, `outForDeliveryAt = now`, and `ops_delivery_tasks.status = 'out_for_delivery'` (matching `assignTaskToRider`).
  3. **`R17` (Cycle Durations & Chemical Reminders)**:
     - Wash cycle = `36 min` (`2160s`), Dry cycle = `40 min` (`2400s`), Detergent = `3 min` (`180s`), Softener = `21 min` (`1260s`, 15m left on 36m wash). Keep minimum completion lock at `30 min` (`1800s`).
  4. **`R18` (Tagging & Packaging Reminders)**:
     - Add `isHandsOnStageNudgeDue(stageData, step, nowMs)` in `dispatch.js` (`initialDelayMs = 10 * 60 * 1000`, `repeatIntervalMs = 5 * 60 * 1000`, anchored to `assignedAt || acceptedAt`, firing until `completedAt`).
     - Wire into `checkUnstartedMachineNudges` in `index.js` for `status in ['tagging', 'packaging']`, bypassing `isDoingHandsOn` suppression for the helper's own tagging/packaging task, sending FCM via `sendFCMStageNudge`, and supporting `snoozeNudge` for `phase === 'hands_on'`.
  5. **`R19` (Multi-Load Aggregation & Per-Load Timings)**:
     - In `submitTagging`, `completeStep`, `completePackaging`, and `persistOpsDetailsToOrder`, aggregate across all sibling `ops_process` docs (`parentOrderId == orderId`): sum `garmentCount`, sum `bundles`, merge deduplicated `packagingPhotos`, collect `packagingVideos: Array<{ url, processId, label }>`, and persist per-load `loadTimings: Record<processId, { label, loadIndex, loadCount, stages }>`.
  6. **`R20` (`reportDamage` Callable)**:
     - Add `reportDamage` action in `opsProcessing`: appends `{ id, processId, loadLabel, photos, videos, note, reportedBy, reportedByName, reportedAt }` via `arrayUnion` to `ops_process/{processId}.damageReports`, `users/{uid}/orders/{orderId}.damageReports`, and `vendors/{vid}/orders/{orderId}.damageReports`.
  7. **`R22` (Dynamic Helper Assignment Rules)**:
     - Read `config/helperAssignmentRules` in `autoAssignTaggingOnPickup` and `autoAssignStage` and pass `helperRules` into `selectHelperForStage`.
     - Add `isHelperAllowedForStage(phone, stage, helperRules)` in `dispatch.js` (falls back to existing defaults when no rule doc/entry exists) and filter candidates before tier/load-balancing.
- **Verification:** `node --check ops/functions/index.js ops/functions/dispatch.js && node --test ops/functions/dispatch.test.js`

# Phase 8 — Lightweight & High-Performance Overhaul (Execution Plan)

**Goal:** Eliminate touch unresponsiveness, stop device overheating and battery drain, make the app lightweight, and optimize read/write load on budget Android devices without altering any existing contracts or business logic.

## Wave 1: Touch Responsiveness & GPS Write-Loop Elimination (Immediate Stability)

### Task 1.1: Fix Runaway GPS Loop in `useRiderLocationSync.ts`
- **File:** `src/utils/useRiderLocationSync.ts`
- **Spec:**
  - Replace `[user?.id, activeRole, myTasks, myDeliveries]` dependency in `useEffect` with a primitive key of task IDs:
    `const activeTasksKey = [myTasks.map(t => t.id).sort().join(','), myDeliveries.map(d => d.id).sort().join(',')].join('|');`
  - Maintain `const lastSyncTimeRef = useRef(0);`. In `broadcastLocation()`, reject execution if `now - lastSyncTimeRef.current < MIN_SYNC_INTERVAL_MS` (60,000ms), breaking any re-trigger loop.
  - Update `lastSyncTimeRef.current = now;` before writing.
  - Ensure error handling never swallows state or triggers retries.
